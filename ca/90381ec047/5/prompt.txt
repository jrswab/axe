24: flag and `stream` TOML field. No provider implementations or loop changes.

32:

36: the rest of the loop stay unchanged. Sub-agents never stream.

43:

45: 
46: Implement `SendStream()` on Ollama (NDJSON), Gemini (SSE), MiniMax
47: (Anthropic-compatible SSE), and OpenCode (delegates to underlying route).
48: Bedrock is deferred to a separate issue (binary event stream framing).
49: 
50: ## Decisions
51: 
52: - **Flag**: `--stream` (explicit opt-in, not auto-detected from TTY)
53: - **TOML**: `stream = true` at agent top level; flag overrides TOML
54: - **Streaming primitive**: `EventStream` struct with `Next()/Close()`
55: - **Retry**: `RetryProvider` delegates `SendStream()` to inner provider without retries
56: - **Sub-agents**: Always use `Send()`, never stream
57: - **Bedrock**: Deferred to separate issue (binary event stream, not SSE)
